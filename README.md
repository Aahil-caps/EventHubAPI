# EventHubAPI

EventHubAPI is a Django REST Framework project that I made for practicing and understanding APIs.

In this project, I worked with different DRF concepts like APIView, GenericAPIView, Mixins and Generic Views.

## What I Practiced

- APIView CRUD operations
- GenericAPIView
- Mixins
- RetrieveUpdateDestroyAPIView
- ListCreateAPIView
- GET, POST, PUT, PATCH and DELETE requests
- Token Authentication
- JWT Authentication
- IsAuthenticated permission
- API testing using Thunder Client

## Authentication

I implemented two types of authentication:

- Token Authentication
- JWT Authentication

I also created protected APIs where authentication is required to access the endpoint.

## Tech Used

- Python
- Django
- Django REST Framework
- SQLite
- JWT
- Thunder Client

## About This Project

I created this project mainly to improve my practical understanding of Django REST Framework and API development.

This project helped me understand how different DRF views, mixins and authentication methods work in real API development.
